# 拼豆豆图生成器

把任意图片转换成拼豆豆图（像素图纸），适配 32×32 / 52×52 / 78×78 / 104×104 等主流智能拼豆板。

**在线使用：** https://cairui03.github.io/pindou/

在 iPhone / iPad 上用 Safari 打开上面的网址，点「分享 → 添加到主屏幕」，就会像一个 App 一样全屏运行。

## 功能

- 图片转豆图，支持裁切 / 留白 / 拉伸三种铺法
- 板子尺寸：32 / 52 / 78 / 104 一键切换，另有 16～128 多种预设和任意「宽×高」自定义
- 色板：通用 24 / 48 / 96 / 256 色，也可以导入自己手上豆子的真实色卡
- 亮度 / 对比度 / 饱和度微调，浅色背景可以一键变成空豆
- 画笔 / 橡皮擦直接在预览图上改，支持撤销
- 导出：精确像素图 PNG（1 像素 = 1 颗豆，可直接导入拼豆 App）、带网格坐标的高清图纸 PNG、色号表 CSV、工程文件 JSON、用豆清单 CSV
- 自动统计每种颜色要几颗豆

## 说明

所有图片都在你自己的设备上处理，不会上传到任何服务器。整个工具是单个 HTML 文件，完全离线可用。
