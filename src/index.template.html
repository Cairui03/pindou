第四步 · 导出与导入拼豆 App

想在智能拼豆板 App 里用？优先导出「精确像素图」——它按 1 像素 = 1 颗豆生成，分辨率就是板子尺寸（如 104×104），在拼豆 App 里选「导入图片 / 自定义图纸」直接导入最准。
iPad / iPhone：点「分享 / 存到相册」，在系统分享菜单里选你的拼豆 App，或选「存储图像」存到相册再从 App 里导入。
要打印图纸对着拼：导出「高清图纸 PNG」，带网格和行列坐标，打印出来照着摆豆。

选了「色号名称」后，导出的高清图纸会在每格中央印上色号，照着摆豆不用来回比对颜色；每格 16px 以下会看不清，建议 24px 以上。

「背景格不标色号」只影响印刷观感：勾上后，连成一整片的大背景不再重复印同一个号，图更清爽；要让每一格都有号（方便别的软件识别），保持不勾即可。

iPad / iPhone 使用说明

  1. 手机 / 平板 用 Safari 打开这个网址：cairui03.github.io/pindou。任何网络都能开，微信里点这个链接也能开。
  2. 当 App 用 网址打开后，点「分享 → 添加到主屏幕」，桌面就有图标了，之后打开是全屏、没有浏览器边框，跟 App 一样。
  3. 电脑上 直接双击本文件、用浏览器打开也能用，全部功能都在（推荐 Chrome / Edge，Safari 也可以）。
  4. 为什么不能直接传文件 iOS 不允许 Safari 打开本地的 .html，微信也会直接拒收——长按文件出现的「打开方式」里永远没有 Safari，这是系统限制。所以手机 / 平板一律走上面的网址。
  5. 选图 点「从相册 / 文件选图」选照片，或点「直接拍照」；iPad 上也能把照片直接拖进页面。
  6. 尺寸 按你手上智能拼豆板的钉数选：104×104（约 62×62 cm 大板）、78×78、52×52、32×32；别的板子用「更多常用尺寸」或直接填宽×高。
  7. 色卡 想严格对应你手上的豆子，就点「导入我手上的豆子色卡」，把你买的豆子的色号填进去；颜色越多渐变越顺，越少越好买。
  8. 导入 App 导出「精确像素图 PNG」→ 点「分享 / 存到相册」→ 分享菜单里选拼豆 App，或先存到相册，再在拼豆 App 里导入这张图。
  9. 微调 生成的豆图可直接用「画笔 / 橡皮擦」在预览区修改，改完再导出。
  10. 算法 本次修复参考了 GitHub 上的高星开源项目：Zippland/perler-beads（Oklab 距离）、LunarXuan/Pindo（线性光降采样、CIEDE2000）、zwhy149/bead-grid-studio（Oklab 粗筛 + CIEDE2000 精排）、ImageOptim/libimagequant（误差扩散阻尼）。色卡数据来自 MIT 许可的 maxcleme/beadcolors。
