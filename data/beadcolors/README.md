# Bead colour data

Vendored from [maxcleme/beadcolors](https://github.com/maxcleme/beadcolors) (MIT License),
directory `gen/v3/` at commit master (fetched 2026-10-28).

Files: mard, hama, hama_maxi, hama_mini, perler, perler_caps, perler_mini, artkal_s, artkal_a, artkal_c, artkal_m, artkal_r, yant, nabbi.

Each CSV row: `code,name,symbol,r,g,b,h,s,l,labL,labA,labB,contributor`.

These are community-sourced colour measurements, not official brand specifications.
The app clusters them into its generic palettes; it does not ship the raw tables to browsers.
